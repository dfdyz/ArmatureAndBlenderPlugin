# 内容清单
1. 骨架配套blender插件，用于切换IK和FK控制器。附带烘焙工具。使用说明请看压缩包内说明文档。
2. EF_MAPPING_FK.py，用于从EF骨架迁移动画的骨骼映射表。用于[BoneAnimCopy插件](https://github.com/kumopult/blender_BoneAnimCopy)。**注意，启用预览后，需要手动关闭本骨架的root骨骼上的BAC_ROT约束。**
3. 模型骨架与示例动画blend文件。
4. EF骨架动画迁移教程视频。

# 注意事项
1. 不要修改骨骼上 ```IK_``` 或 ```FK_``` 开头的约束，除非你知道插件是如何工作的。
